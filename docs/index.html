Quick start快速開始

Three steps on the machine you want to turn into an AI server.在要變成 AI 主機的那台電腦上,三步驟。

🪟 Windows 10 / 11

Unzip the release解壓縮

Download the latest release zip and extract it anywhere.下載最新 release 壓縮檔,解壓到任意位置。

Double-click 安裝.bat雙擊 安裝.bat

Answer the prompts (Enter = defaults): Ollama version, allow LAN, download a model.照問題回答(Enter＝預設):Ollama 版本、要不要開放區網、要不要先下載模型。

Copy your login code記下登入碼

The panel opens and shows a one-time login code. Done.面板自動打開並顯示登入碼。完成。

Scripted / unattended:免問、可批次:

.\install.ps1 -Quiet -OllamaVersion 0.40.13 ^
  -Models qwen3.5:9b -Lan

🐧 Linux (systemd)

Ubuntu / Debian / Fedora / RHEL. Installs Ollama via its official script, runs the panel as a systemd service.Ubuntu／Debian／Fedora／RHEL。用官方腳本裝 Ollama,面板跑成 systemd 服務。

sudo bash install.sh

Options mirror Windows:選項跟 Windows 對應:

sudo bash install.sh --yes --lan \
  --ollama-version 0.40.13 \
  --model qwen3.5:9b

Forgot the code? sudo /opt/ai-server-kit/show-token.sh忘記登入碼? sudo /opt/ai-server-kit/show-token.sh

How to use it怎麼使用

Open the panel URL (or scan it on your phone), enter the login code, and use the four tabs.打開面板網址(或用手機開),輸入登入碼,用四個分頁。

📊 Status狀態

Watch CPU, memory and GPUs in real time. See which models are loaded and whether they fit in VRAM.即時看 CPU、記憶體、顯示卡。看載入了哪些模型、放不放得進顯示卡記憶體。

🧩 Models模型

Search the whole open-model world, download with a tap, or import your own GGUF / safetensors — the panel identifies it first.搜尋全網開源模型、點一下下載,或匯入自己的 GGUF／safetensors——面板會先辨識它。

💬 Chat對話

Pick a model and talk. Turn on thinking, attach an image, or let it read the machine's live status.選一個模型直接聊。開思考模式、傳圖片,或讓它讀這台的即時狀態。

🖥️ Terminal終端機

Run commands on the host from anywhere. It keeps the working directory and reconnects after a reload.從任何地方對主機下指令。會記得資料夾,重整後自動接回。

Deploy to others & collect models — with consent發給別人用、收集模型——都要同意

Distributing the kit? The optional "return a model to the producer" feature is off by default and never silent.要發給別人用?選用的「把模型回傳給製作人」功能預設關閉,絕不背景偷傳。

⚠ Three gates, all required:三關,缺一不可:

  1. The producer sets a receive URL in config.json (share.url). Without it, no sharing button ever appears.製作人在 config.json 設收件位置(share.url)。沒設,分享按鈕根本不出現。
  2. On first run the user must accept a usage agreement that clearly discloses this optional sharing. Accepting makes the button available; it does not send anything.第一次開面板要同意使用協議(協議清楚寫明這個選用的分享功能)。同意只是讓按鈕出現,本身不會傳送任何東西。
  3. Even then, each unknown model is sent only when the user clicks "import & return" and confirms. Public models are never involved.就算開了,也只有匯入「網路上找不到」的模型、使用者按「匯入並回傳」並確認才會傳。公開模型完全不涉及。

Producer-side receiver製作人端:收模型伺服器

A tiny standalone server (receiver/) that accepts the uploads, verifies the token, stores them, and shows a listing page.一支獨立小程式(receiver/):收上傳、驗 token、存檔、附清單頁。

# on the producer's machine
pwsh receiver/setup.ps1            # makes config.json + a random token
python receiver/server.py --config receiver/config.json

Then point the panel at it: "share": { "url": "https://your-host/upload", "label": "Producer", "token": "same-token" }再把面板指過去:"share": { "url": "https://你的網域/upload", "label": "製作人", "token": "同一組通關碼" }

Not legal advice. What protects users here is that no model is ever uploaded automatically — each one needs an explicit per-model confirmation. Have a lawyer review the agreement before relying on it commercially, and always serve the receiver over HTTPS. 非法律意見。這裡真正的保障是:任何模型都不會自動上傳,每一個都要本人逐一確認。正式營運前請律師看過協議,收模型伺服器一定要走 HTTPS。
